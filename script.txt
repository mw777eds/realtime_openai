Script: Session_SaveState [ sessionId ; payloadJSON ]
Purpose: Upsert the unified session JSON (settings + history) keyed by sessionId. Merge only provided keys.

Parameters (JSON):
- { "sessionId":"...", "settings": { ... }, "history":[ ... ] }
  - Either key can be present; update only what’s provided.

Pseudo-steps:
1) Set Variable [ $raw = Get ( ScriptParameter ) ]
2) If [ IsEmpty ( $raw ) ] Exit Script [ Result: "ERROR:EMPTY_PARAM" ]
3) Set Variable [ $json = JSONFormatElements ( $raw ) ]
4) Set Variable [ $sessionId = JSONGetElement ( $json ; "sessionId" ) ]
5) If [ IsEmpty ( $sessionId ) ] Set Variable [ $sessionId = $$SessionId ]
6) If [ IsEmpty ( $sessionId ) ] Exit Script [ Result: "ERROR:MISSING_SESSION" ]
7) Go to Layout [ “Sessions” (Sessions) ]
8) Enter Find Mode [ Pause: Off ]
9) Set Field [ Sessions::SessionId ; $sessionId ]
10) Perform Find
11) If [ Get ( FoundCount ) = 0 ]
      New Record/Request
      Set Field [ Sessions::SessionId ; $sessionId ]
    End If
12) Set Variable [ $current = Sessions::SessionJSON ]
13) If [ IsEmpty ( $current ) ] Set Variable [ $current = "{}" ]
14) If [ not IsEmpty ( JSONGetElement ( $json ; "settings" ) ) ]
      Set Variable [ $current = JSONSetElement ( $current ; "settings" ; JSONGetElement ( $json ; "settings" ) ; JSONRaw ) ]
    End If
15) If [ not IsEmpty ( JSONGetElement ( $json ; "history" ) ) ]
      Set Variable [ $current = JSONSetElement ( $current ; "history" ; JSONGetElement ( $json ; "history" ) ; JSONRaw ) ]
    End If
16) Set Field [ Sessions::SessionJSON ; $current ]
17) Set Field [ Sessions::UpdatedAt ; Get ( CurrentTimestamp ) ]
18) Commit Records/Requests [ No dialog ]
19) Exit Script [ Result: "{\"success\":true}" ]

Script: Session_GetState [ sessionId ]
Purpose: Return the unified session JSON (settings + history) for the given sessionId.

Parameters (JSON):
- { "sessionId":"..." } (if omitted, use $$SessionId)

Pseudo-steps:
1) Set Variable [ $raw = Get ( ScriptParameter ) ]
2) If [ IsEmpty ( $raw ) ] Exit Script [ Result: "{\"success\":false,\"error\":\"EMPTY_PARAM\"}" ]
3) Set Variable [ $json = JSONFormatElements ( $raw ) ]
4) Set Variable [ $sessionId = JSONGetElement ( $json ; "sessionId" ) ]
5) If [ IsEmpty ( $sessionId ) ] Set Variable [ $sessionId = $$SessionId ]
6) If [ IsEmpty ( $sessionId ) ] Exit Script [ Result: "{\"success\":false,\"error\":\"MISSING_SESSION\"}" ]
7) Go to Layout [ “Sessions” (Sessions) ]
8) Enter Find Mode [ Pause: Off ]
9) Set Field [ Sessions::SessionId ; $sessionId ]
10) Perform Find
11) If [ Get ( FoundCount ) = 0 ]
      Exit Script [ Result: "{\"success\":true,\"result\":{\"sessionId\":\"" & $sessionId & "\",\"settings\":{},\"history\":[]}}" ]
    End If
12) Set Variable [ $out = JSONSetElement ( "{}" ;
      [ "success" ; 1 ; JSONBoolean ] ;
      [ "result.sessionId" ; $sessionId ; JSONString ] ;
      [ "result" ; Sessions::SessionJSON ; JSONRaw ]
    ) ]
13) Exit Script [ Result: $out ]

Script: Grid_SaveLayout [ sessionId ; payloadJSON ]
Purpose: Save the current mode’s user default layout (per user, not per session). Accepts one mode at a time.

Parameters (JSON):
- { "key":"docked"|"undocked", "sessionId":"...", "settings": { version, columns, cellHeight?, float, voice, text, toasts|debug, showToolCalls?, layout:[ {x,y,w,h,widget}, ... ] } }

Behavior:
- Upsert per-user defaults for the provided key (AccountName + Key).
- Store the provided settings and layout array for that key. Other key remains unchanged.

Return:
- "{\"success\":true}"

******************************
Script: Grid_LoadLayout [ sessionId ; key ]
Purpose: Return the saved layout envelope (prefer session state if you maintain it; otherwise user defaults) for the requested key.

Parameters (JSON):
- { "sessionId":"...", "key":"docked"|"undocked" }

Behavior:
- Look up per-session state first if you maintain session layouts; else skip.
- Fallback to per-user defaults by AccountName + Key.
- Return an envelope shaped as:
  {
    "key": "docked"|"undocked",
    "settings": {
      "version": 1,
      "columns": 12,
      "cellHeight": 8,
      "float": true,
      "voice": true,
      "text": true,
      "toasts": true,
      "showToolCalls": true,
      "layout": {
        "docked": [ ...optional... ],
        "undocked": [ ...optional... ]
      }
    }
  }
- It is OK to include only the requested key inside settings.layout.

Return:
- The JSON envelope above, or "" if none.

******************************
Script: Grid_RestoreDefaultLayout [ sessionId ; key ]
Purpose: Return a default layout envelope for the given mode key. Web will apply it as a reset.

Parameters (JSON):
- { "sessionId":"...", "key":"docked"|"undocked" }

Behavior:
- Build and return an envelope with settings.layout containing only that key’s default nodes.
- Include default toggle values (voice/text/toasts/float) as you prefer.

Return:
- The JSON envelope.

Script: Realtime_Init [ sessionId ]
Purpose: Generate an ephemeral OpenAI token and return WebRTC session config to the Web Viewer.

Parameters (JSON):
- { "sessionId":"..." }

Behavior:
- Resolve model, instructions, tools, and session configuration.
- Call JavaScript in Web Viewer: window.applyRealtimeInit(JSON) with:
  {
    "success": true,
    "result": {
      "ephemeralKey": "...",
      "model": "gpt-4o-realtime-preview",
      "instructions": "You are a helpful AI assistant.",
      "tools": [],
      "toolChoice": "auto",
      "sessionConfig": {
        "modalities": ["text","audio"],
        "voice": "verse"
      }
    }
  }

Return:
- "{\"success\":true}" (optional; primary handoff is via JS callback)

Script: CallTools [ sessionId ; toolCallsJSON ]
Purpose: Execute tool calls emitted by the model and return outputs to the Web Viewer.

Parameters (JSON):
- { "toolCalls":[ { "name":"...", "call_id":"...", "arguments":{...} }, ... ] }

Behavior:
- For each tool call, run the corresponding FileMaker script/workflow.
- Use "Perform JavaScript in Web Viewer" to call:
  - window.sendToolResponse(JSON.stringify({ call_id:"...", output:{...} }))
  - After the last tool response, call window.createModelResponse()

Return:
- "{\"success\":true}"

Script: Chat_SendMessage [ sessionId ; messageJSON ]
Purpose: Text-mode fallback when Realtime is not connected.

Parameters (JSON):
- { "role":"user", "message":"..." }

Behavior:
- Append user message to canonical history (Sessions::SessionJSON.history).
- Call OpenAI Chat Completions; append assistant message and any tool events.

Return:
- "{\"success\":true}"
