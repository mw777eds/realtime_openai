FileMaker Scripts Mockups — Save/Load Grid Layout (per-mode)

Overview
- Two scopes of persisted layouts:
  - Session scope (sessionId + key): authoritative per-chat layouts for Docked/Undocked. Always updated at boundaries (session switch, viewer close) and optionally on debounced grid changes. Includes session-only widgets (e.g., artifacts).
  - Machine scope (machineId + key): template defaults for Docked/Undocked. Updated only on explicit “Save Layout” action. Used to seed new sessions and “Restore Default Layout”.
- Precedence when applying a layout (for a given mode key):
  1) Session scope (sessionId + key), else
  2) Machine scope (machineId + key), else
  3) App defaults.
- Web app calls:
  - Grid_SaveLayout(sessionId; JSON): saves a layout envelope (scope:"session" or "machine") for the current mode key ("docked"|"undocked").
  - Grid_LoadLayout(sessionId; machineId; key): returns the saved envelope for the requested key/scope (see parameters), or empty if none.
  - Optionally: Grid_RestoreDefaultLayout(sessionId; key): returns a default envelope for the requested key.
- History persistence (separate from layout):
  - Chat_SaveHistory(sessionId; JSON): append-or-snapshot canonical history.
  - Chat_GetHistory(sessionId): returns canonical history for the chat.
- Flush policy (recommended):
  - History: on response.done, on transcript commit, on tool_call/tool_result, on text submit, on session switch, and on viewer close; optional 30–60s autosave if dirty.
  - Session layout: on session switch and viewer close; optional debounced autosave on dragstop/resizestop/remove.
  - Machine layout: only when the user clicks Save Layout.

Suggested schema (example)
- Table: GridLayouts
  - MachineId (Text)   // persistent device id
  - SessionId (Text)   // logical chat session id
  - Key (Text)         // "docked" | "undocked"
  - Payload (Text)     // JSON string as saved
  - Float (Number)     // 0/1
  - UpdatedAt (Timestamp)
- Relationship: GridLayouts by MachineId + SessionId + Key (Unique)

- Table: AppPreferences (optional)
  - MachineId (Text)
  - SessionId (Text)
  - Settings (Text) // JSON: { voice, text, toasts, float, mode }
  - UpdatedAt (Timestamp)

JSON payload from Web (layout envelope)
{
  "scope": "session" | "machine",
  "key": "docked" | "undocked",
  "machineId": "ABCDEF-123...",               // persistent device id
  "sessionId": "session-xyz",                 // required when scope = "session"
  "settings": {
    "version": 1,
    "columns": 12,
    "cellHeight": 8,                          // optional, px per row
    "float": true,
    "voice": true,
    "text": true,
    "toasts": true,                           // or "debug": true (front-end maps debug->toasts)
    "layout": [
      { "widget": "voice",  "x": 0, "y": 0,  "w": 2,  "h": 2 },
      { "widget": "text",   "x": 2, "y": 0,  "w": 10, "h": 5 },
      { "widget": "toasts", "x": 0, "y": 2,  "w": 2,  "h": 3 }
      // If undocked, include: { "widget": "convo", "x": ..., "y": ..., "w": ..., "h": ... }
      // Session scope may also include artifact widgets
    ]
  }
}

Script: Grid_SaveLayout [ sessionId ; payloadJSON ]
Purpose: Save current mode’s layout for a session (scope:"session") or update machine defaults (scope:"machine").

Parameters:
- ScriptParameter is a JSON string with envelope:
  { scope, key, machineId, sessionId, settings{ version, columns, cellHeight?, float, voice, text, toasts|debug, layout[] } }

Pseudo-steps:
1) Set Variable [ $raw = Get ( ScriptParameter ) ]
2) If [ IsEmpty ( $raw ) ] 
     Show Custom Dialog [ "Missing payload" ]
     Exit Script [ Result: "ERROR:EMPTY_PARAM" ]
   End If
3) Set Variable [ $json = JSONFormatElements ( $raw ) ]
4) Set Variable [ $scope = Lower ( JSONGetElement ( $json ; "scope" ) ) ]
5) Set Variable [ $key = JSONGetElement ( $json ; "key" ) ]
6) If [ IsEmpty ( $key ) ] Set Variable [ $key = "docked" ]
7) Set Variable [ $sessionId =
      Case(
        not IsEmpty ( JSONGetElement ( $json ; "sessionId" ) ) ; JSONGetElement ( $json ; "sessionId" ) ;
        not IsEmpty ( $$SessionId ) ; $$SessionId ;
        Get ( UUID )
      )
   ]
8) Set Variable [ $machineId =
      Case(
        not IsEmpty ( JSONGetElement ( $json ; "machineId" ) ) ; JSONGetElement ( $json ; "machineId" ) ;
        $$MachineId
      )
   ]
9) Set Variable [ $float = JSONGetElement ( $json ; "settings.float" ) ]
10) Go to Layout [ “GridLayouts” (GridLayouts) ]
11) Enter Find Mode [ Pause: Off ]
12) If [ $scope = "machine" ]
      Set Field [ GridLayouts::MachineId ; $machineId ]
      Set Field [ GridLayouts::SessionId ; "" ]
      Set Field [ GridLayouts::Key ; $key ]
    Else
      Set Field [ GridLayouts::SessionId ; $sessionId ]
      Set Field [ GridLayouts::MachineId ; $machineId ] // optional but useful
      Set Field [ GridLayouts::Key ; $key ]
    End If
13) Perform Find
14) If [ Get ( FoundCount ) = 0 ]
      New Record/Request
      Set Field [ GridLayouts::Key ; $key ]
      If [ $scope = "machine" ]
        Set Field [ GridLayouts::MachineId ; $machineId ]
        Set Field [ GridLayouts::SessionId ; "" ]
      Else
        Set Field [ GridLayouts::SessionId ; $sessionId ]
        Set Field [ GridLayouts::MachineId ; $machineId ]
      End If
    End If
15) Set Field [ GridLayouts::Payload ; $json ]
16) Set Field [ GridLayouts::Float ; Case ( $float ; 1 ; 0 ) ]
17) Set Field [ GridLayouts::UpdatedAt ; Get ( CurrentTimestamp ) ]
18) Commit Records/Requests [ No dialog ]
19) Exit Script [ Result: "OK" ]

Script: Grid_LoadLayout [ sessionId ; machineId ; key ]
Purpose: Return the saved layout envelope for the requested scope and key to the Web Viewer.

Parameters (JSON preferred):
- { "scope":"session"|"machine", "sessionId":"...", "machineId":"...", "key":"docked" }
- If scope omitted:
  - If sessionId present → load session scope (SessionId + Key).
  - Else → load machine scope (MachineId + Key).

Pseudo-steps:
1) Set Variable [ $raw = Get ( ScriptParameter ) ]
2) Set Variable [ $key =
      Case(
        PatternCount ( $raw ; "{" ) ;
          JSONGetElement ( $raw ; "key" ) ;
        not PatternCount ( $raw ; "{" ) ;
          $raw ;
        "" )
   ]
3) If [ IsEmpty ( $key ) ] Set Variable [ $key = "docked" ]
4) Set Variable [ $scope = Lower ( JSONGetElement ( $raw ; "scope" ) ) ]
5) Set Variable [ $sessionId =
      Case(
        PatternCount ( $raw ; "{" ) ;
          JSONGetElement ( $raw ; "sessionId" ) ;
        not PatternCount ( $raw ; "{" ) and not IsEmpty ( $$SessionId ) ;
          $$SessionId ;
        ""
      )
   ]
6) Set Variable [ $machineId =
      Case(
        PatternCount ( $raw ; "{" ) ;
          JSONGetElement ( $raw ; "machineId" ) ;
        not PatternCount ( $raw ; "{" ) and not IsEmpty ( $$MachineId ) ;
          $$MachineId
      )
   ]
7) If [ IsEmpty ( $scope ) ]
      If [ not IsEmpty ( $sessionId ) ]
        Set Variable [ $scope = "session" ]
      Else
        Set Variable [ $scope = "machine" ]
      End If
   End If
8) Go to Layout [ “GridLayouts” (GridLayouts) ]
9) Enter Find Mode [ Pause: Off ]
10) If [ $scope = "machine" ]
      Set Field [ GridLayouts::MachineId ; $machineId ]
      Set Field [ GridLayouts::SessionId ; "" ]
      Set Field [ GridLayouts::Key ; $key ]
    Else
      Set Field [ GridLayouts::SessionId ; $sessionId ]
      Set Field [ GridLayouts::Key ; $key ]
    End If
11) Perform Find
12) If [ Get ( FoundCount ) = 0 ]
      Exit Script [ Result: "" ] // none saved
    End If
13) Set Variable [ $payload = GridLayouts::Payload ]
14) Exit Script [ Result: $payload ]

Script: App_Init [ sessionId ; machineId ]
Purpose: Return initialization bundle for the WebView.

Parameters (JSON prefered):
- { "sessionId": "...", "machineId": "..." }

Returns (JSON):
{
  "machineId": "...",
  "sessionId": "...",
  "settings": { "voice": false, "text": true, "toasts": true, "float": true, "mode": "docked" },
  "layout": { ...payload from Grid_LoadLayout... } | "",
  "history": [ ...canonical messages... ]              // optional, may be empty array if none
}

Pseudo-steps:
1) Parse params → $sessionId, $machineId.
2) Load preferences from AppPreferences by MachineId + SessionId (fallback: by MachineId, then defaults).
3) Determine mode = settings.mode ("docked"|"undocked"), default "docked".
4) Call Grid_LoadLayout with (scope:"session", sessionId, key:mode). If empty, call Grid_LoadLayout with (scope:"machine", machineId, key:mode).
5) Call Chat_GetHistory(sessionId) to get canonical history (optional).
6) Build JSON result { machineId, sessionId, settings, layout, history }.
7) Exit Script [ Result: $json ]

Script: Settings_SavePreferences [ sessionId ; machineId ; settingsJSON ]
Purpose: Persist UI toggles per machine and session.

Parameters:
- { "sessionId": "...", "machineId": "...", "settings": { "voice":..., "text":..., "toasts":..., "float":..., "mode":"docked|undocked" } }

Pseudo-steps:
1) Parse params → $sessionId, $machineId, $settings.
2) Find AppPreferences by MachineId + SessionId.
3) Upsert record; set Settings = $settings; UpdatedAt = now.
4) Exit Script [ Result: "OK" ]

Script: Grid_SaveLayout [ sessionId ; machineId ; payloadJSON ]
Purpose: Save layout keyed by machine and session.

Parameters: payload as described in “JSON payload from Web”.

Pseudo-steps differences vs V1:
- Parse $machineId := JSONGetElement($json; "machineId")
- Parse/resolve $sessionId := JSONGetElement($json; "sessionId") or $$SessionId
- Parse/resolve $key := JSONGetElement($json; "key") default "docked"
- Find GridLayouts by MachineId + SessionId + Key
- Upsert Payload, Float, UpdatedAt

Script: Grid_LoadLayout [ sessionId ; machineId ; key ]
Purpose: Return saved layout for machineId + sessionId + key.

Parameters (JSON or plain):
- { "sessionId":"...", "machineId":"...", "key":"docked" } or plain key + rely on $$ vars.

Pseudo-steps:
1) Resolve $key (default "docked"), $sessionId, $machineId.
2) Find GridLayouts by MachineId + SessionId + Key.
3) If none, return "".
4) Return Payload.

Notes
- If you need per-user persistence, include AccountName in the key or store AccountName alongside MachineId for multi-user shared machines.
- For autosave UX:
  - History: flush on response.done, transcript commit, tool_call/tool_result, text submit, session switch, and viewer close; optionally every 30–60s if dirty.
  - Session layout: flush on session switch and viewer close; optionally debounce flush on dragstop/resizestop/remove.
  - Machine layout: only on explicit Save Layout action from the menu.
- Realtime start: do not call initializeWebRTC on page load; start it when the Voice widget is enabled/mounted (or via explicit FileMaker call after bootstrap).
- Optional combined script: App_SaveSessionState(sessionId; JSON)
  - Accepts a payload: { sessionId, machineId, mode, history[], layoutEnvelope{ scope:"session", key, machineId, sessionId, settings{…} } }
  - Server-side splits into Chat_SaveHistory + Grid_SaveLayout to persist both atomically for the session.
