******************************
Script: Chat_SaveHistory [ sessionId ; historyJSON ]
Purpose: Persist the canonical conversation (“text + tools”) for a session.

Parameters (JSON):
- { "sessionId": "...", "history": [ {canonical items as in instructions.md §4} ] }

Pseudo-steps:
1) Set Variable [ $raw = Get ( ScriptParameter ) ]
2) If [ IsEmpty ( $raw ) ] Exit Script [ Result: "ERROR:EMPTY_PARAM" ]
3) Set Variable [ $json = JSONFormatElements ( $raw ) ]
4) Set Variable [ $sessionId = JSONGetElement ( $json ; "sessionId" ) ]
5) If [ IsEmpty ( $sessionId ) ]
     Set Variable [ $sessionId = $$SessionId ]
   End If
6) If [ IsEmpty ( $sessionId ) ] Exit Script [ Result: "ERROR:MISSING_SESSION" ]
7) Set Variable [ $history = JSONGetElement ( $json ; "history" ) ]
8) Go to Layout [ “ChatHistory” (ChatHistory) ]
9) Enter Find Mode [ Pause: Off ]
10) Set Field [ ChatHistory::SessionId ; $sessionId ]
11) Perform Find
12) If [ Get ( FoundCount ) = 0 ]
      New Record/Request
      Set Field [ ChatHistory::SessionId ; $sessionId ]
    End If
13) Set Field [ ChatHistory::HistoryJSON ; $history ]
14) Set Field [ ChatHistory::UpdatedAt ; Get ( CurrentTimestamp ) ]
15) Commit Records/Requests [ No dialog ]
16) Exit Script [ Result: "{\"success\":true}" ]

******************************
Script: Chat_GetHistory [ sessionId ]
Purpose: Return the canonical conversation for a session.

Parameters (JSON):
- { "sessionId": "..." }

Pseudo-steps:
1) Set Variable [ $raw = Get ( ScriptParameter ) ]
2) If [ IsEmpty ( $raw ) ] Exit Script [ Result: "{\"success\":false,\"error\":\"EMPTY_PARAM\"}" ]
3) Set Variable [ $json = JSONFormatElements ( $raw ) ]
4) Set Variable [ $sessionId = JSONGetElement ( $json ; "sessionId" ) ]
5) If [ IsEmpty ( $sessionId ) ]
     Set Variable [ $sessionId = $$SessionId ]
   End If
6) If [ IsEmpty ( $sessionId ) ] Exit Script [ Result: "{\"success\":false,\"error\":\"MISSING_SESSION\"}" ]
7) Go to Layout [ “ChatHistory” (ChatHistory) ]
8) Enter Find Mode [ Pause: Off ]
9) Set Field [ ChatHistory::SessionId ; $sessionId ]
10) Perform Find
11) If [ Get ( FoundCount ) = 0 ]
      Exit Script [ Result: "{\"success\":true,\"result\":{\"sessionId\":\"" & $sessionId & "\",\"history\":[]}}" ]
    End If
12) Set Variable [ $out = JSONSetElement ( "{}" ;
      [ "success" ; 1 ; JSONBoolean ] ;
      [ "result.sessionId" ; $sessionId ; JSONString ] ;
      [ "result.history" ; ChatHistory::HistoryJSON ; JSONRaw ]
    ) ]
13) Exit Script [ Result: $out ]
